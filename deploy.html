Deployment steps

✓
Code pushed to GitHub
app.py + requirements.txt live on main
2
Open Streamlit Cloud
Go to share.streamlit.io and sign in with your GitHub account
3
Create a new app
Click New app, then fill in:
Repository: simplecrag-spec/card-app
Branch: main
Main file path: app.py
4
Deploy & bookmark
Click Deploy. After ~2 min you'll get a URL like https://yourname-card-app.streamlit.app. Open it on your phone → Add to Home Screen.
